## 讲解错题与未作答题

这一节首先定义笔记里 `错题讲解` 折叠块的固定写法；聊天默认不展开（「评分后的回复」只给得分行、判定表格与后续菜单，不展开讲解）。用户明确要求讲某道题、或从历史菜单选择 `explain-current-exercise` 时，才按同一模板在聊天里补讲。不要只说“不能说”“不自然”或重复规则标签。每道错题固定使用下面的模板输出，无序列表标记、加粗小标签、五步顺序都不得省略或合并。未作答题同样必须讲解：沿用同一五步结构，只把第 2 步标签换成 `为什么答不出`，写清卡在哪一步，并给出可直接背的参考表达。

````markdown
**错题 N：<用户答案或错误片段>（第 X 题）**

- **考点**：本题实际考查的知识点。
- **为什么错**：指出触发该判断的英语机制，例如可数/不可数的计量方式、冠词和量词的搭配条件、时态对应、词义边界、句子结构或语域限制；一行有多个独立错因时逐条写成缩进子项，一条一点。
- **英语的表达逻辑**：说明英语把这个概念当作可数单位、不可数内容、动作过程、状态结果还是具体事件处理。
- **正确表达**：给出本题纠正后的代表句，附中文翻译。
- **举一反三**：围绕本轮错误点，给出至少两条避开同类错误、套用纠正后结构的换场景例句；逐条写成缩进子项，一句一行，不要用 `／`、`/` 或 `；` 同行串接；中文直觉和英语分类不同时，明确对比。
````

未作答题的模板写法：

````markdown
**未作答题 N：<用户回复，例如“不会”>（第 X 题）**

- **考点**：本题实际考查的知识点。
- **为什么答不出**：这道题卡在哪一步，例如缺少可套用的框架、不会选动词、拿不准冠词，或根本没有产出思路。
- **英语的表达逻辑**：说明英语把这个概念当作可数单位、动作过程、状态结果还是具体事件处理。
- **正确表达**：给出参考表达代表句，附中文翻译。
- **举一反三**：围绕本轮卡点，给出至少两条同类场景的换场景例句；逐条写成缩进子项，一句一行，不要同行串接。
````

模板内各条仍须遵守：

- 选择题在模板之后逐项解释关键干扰项，再回到第 2、4 步的机制与正确表达。
- 改错或翻译题先说明用户原句想表达什么，再区分核心错误、自然度问题和可选风格改写。
- 避免把“规则名称”当作原因；规则名称后面必须跟一句可理解的机制解释。
- 翻译或整句产出类错题允许在五步之后追加一行“整句参考版本”，这是模板唯一允许的额外步骤；未作答题同样适用。
- 多道错题按题号顺序排列，每题之间空一行；模板用编号列表，不要改写成表格。表格只用于多题并列的得分与判定汇总。
- 错题、部分正确的题、未作答题以及用户明确跳过的题都要用模板讲解；未作答题给出参考表达，不把“没作答”当成无需讲解的理由。


## 场景对话错题

未作为评分复习任务的互动角色扮演不调用 `complete-review`。默认的完整场景对话脚本、以及 `focus-story` 输出的完整故事都只是示例材料，不记录错题。只有用户明确参与互动角色扮演并确实出现、得到纠正的英语错误时，才把本轮所有错误组成一批记录，运行一次 `batch-upsert`；每条按仓库根目录 `AGENTS.md` 的判型规则落进对应知识分类（拼写 / 词形 → `vocabulary`，搭配 → `phrases`，结构 / 时态 → `grammar`，语气 / 语域 → `usage`），判不出类型才留 `errors`。完全正确时不写错误记录。
