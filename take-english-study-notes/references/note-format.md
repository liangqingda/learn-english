# 复习笔记格式与写入规则

本文件是 `learning-record-notes/` 笔记的**唯一规则来源**；`SKILL.md`、`README.md`、`learning-record-notes/README.md`
只做指引，不再复述细则。版式本身以 `take-english-study-notes/templates/review-note.md` 为准，校验规则由
`take-english-study-notes/scripts/check_note.py` 强制执行。三处冲突时按「模板 → 校验器 → 本文件」的顺序取用。

## 何时写、写到哪

- 复习 / 练习 / 套题笔记只在用户已经提交答案、且评分与错题保存成功（或用户明确放弃保存）之后写；未作答的题组、
  纯菜单、`stats` / `history` / `paper-get` 查询、`next-review` 领取阶段都不写文件。
- **笔记按需生成，不要求一条记录一份**：记录只有被首次讲解（`note.py explain`）或被抽中复习（`review-round` 的 `note` 段）
  时才落一份笔记文件；`batch-upsert` 只写规范记录、不建笔记。从没被讲解、也没被复习过的记录没有笔记文件属于正常状态，
  `check --all` 会把它们列进 `missing_notes` 只做体检报告、不算校验错误；需要补建时仍用 `note.py explain`。
- 讲解笔记由 `learn-from-english` 在首次讲解后写：本轮实质讲解的每条记录各写一份，用 `note.py explain` 创建。
  讲解是**文件级固定小节** `## 讲解`，紧跟 `## 基础信息` 表格之后、位于所有日期区块之前：一个知识点只有一次首次讲解，
  复习才会多轮，所以讲解不参与轮次编号；之后这条记录的每次复习继续用 `note.py append` 把新日期区块插到同一个文件最前
  （`append` 会按记录 ID 自动定位已存在的文件）。
  一份笔记只有一份 `## 讲解`；文件已存在讲解时 `explain` 返回 `duplicate: true`，不要写第二份。
- 保存失败时只在当前对话保留内容，不落盘；用户明确放弃保存后仍写笔记，但追踪字段标注「评分未保存（已放弃）」。
- 一轮复习只写一个文件；分段提交答案时只在最终评分结束时写一次完整版本。套题按整套写一个文件，不按 Part 拆分。
- 同一个记录反复复习会**持续改写同一个文件**：开启新一轮时在最前插入一个日期区块（最新一轮在最上，旧区块依次后移），同一轮内的修改（补错题讲解、补场景对话原文、追加菜单项、隔天再补题组）就地改同一个区块，不新开区块。
  因此区块内同时保留两个时间：`笔记生成时间` 只记首次写入，`笔记更新时间` 记该区块最后一次修改，两者相同时说明写过之后没再改。
- **讲解型内容一律进文件级讲解区，日期区块只放习题**：菜单项里只有「讲解要点 / 对比 / 场景对话 / 小故事」这类内容时，写成
  `## 讲解` 之后的文件级小节；只有该菜单项**带习题**时，才在日期区块里另建一个同名小节并只写习题（题号、题目、答案、判定、讲解折叠块）。
  同一条记录的讲解要点只在第一轮写一次，后续重复选择只往日期区块写习题，不再改动讲解区。
  同一个菜单项被重复选中时，除场景对话与小故事外不再重复记录（例如「对比相近表达」记录过一次后，后续不再新建小节）。
  **带习题的菜单项可以先落盘讲解要点**：讲解当轮就用 `append-explain-section` 把 `**讲解要点**` 写进文件级同名小节
  （这一节还没有习题时不需要 `复习历史` 索引，属正常状态），习题部分仍等用户提交、评分成功后再用 `append-section`
  写进该轮最新的日期区块；这样「只讲解、不答题」的轮次也不会丢掉讲解内容。这一节已存在时再次讲解只用
  `replace --rewrite-section` 就地修正，不新建第二节。
- 场景对话与小故事是例外：每选中一次就要追加一段完整原文，第二段起按 `场景对话原文 1 / 2`、`故事原文 1 / 2` 编号。
- 只要本轮有习题，就按 0 至 10 分给出得分，题量与错题数一并记录。复习与套题把得分写进规范记录；
  `follow-up-learning` 练习、`error-clusters` 专题练习、互动角色扮演里用户实际作答的题组同样计分，
  但得分只写进笔记（`本轮得分` 填 `x / 10`、`分类 · 状态变化` 填 `<category> · 未入库`），不调用 `complete-review`。
  纯展示项（场景对话脚本、小故事、讲解）不产生题组，也就没有本轮得分。
- 笔记按分类分目录存放：`learning-record-notes/<category>/<category>-<slug>.md`，目录名必须等于文件名前缀
  （`errors/errors-out-west.md`、`paper/paper-cet6-xxx.md`）。目录与文件名前缀不一致、或直接放在
  `learning-record-notes/` 根下都会被校验器拒绝；`categories.json` 与 `README.md` 留在根目录。
- 文件名不带日期：`learning-record-notes/<category>/<category>-<slug>.md`。`category` 只能取 `learning-record-notes/categories.json`
  里声明的键（现有 `vocabulary`、`phrases`、`grammar`、`usage`、`errors`；套题用 `paper`）；一轮练习即使实质考查 ≥2 个分类，
  也只写「锚点记录」所在的分类——锚点取本轮错得最多、
  或主要考查的那一条记录，它的记录 ID 就决定文件名；禁止 `mixed`、`misc`、`practice` 等自造前缀。
  写入命令仍接受旧式平铺路径（`learning-record-notes/<category>-<slug>.md`）：`NoteStore.resolve`
  会按文件名前缀算出分类目录，并在第一次写入时把旧文件移进去。
- **分类清单只有一份**：键、中文标题、展示顺序与 `hidden` 都由 `learning-record-notes/categories.json` 定义。
  改标题、调列顺序、把某类从看板藏起来只改这个文件，不要再抄一份到笔记正文、复习菜单或其他项目
  （`my-dashboard` 的英语页直接读它来排看板列）。**新增一个全新分类**除了改该文件，还要新建同名目录
  （`learning-record-notes/<new-key>/`）、同步本节的
  分类列表、`check_note.py` 的分类集合和下面的「各分类必写栏」——校验器靠那里拦自造前缀。
  别处读到的不在清单里的前缀，说明这里是唯一漏改的地方。
- `slug` 取记录 `id` 或 `paper_id` 的语义部分，只保留小写字母、数字、连字符。记录 `key` 与 `slug`
  一律用 ASCII，中文主题必须意译成英文短语（`usage:after-不宜直接当-later-连接后续动作`
  应写成 `usage:after-vs-later-sequence`），不得把中文直接拼进 `key`；`learning_records.py` 会把
  非 ASCII 字符压掉而报 key 无效，`check_note.py` 也会拒收中文文件名。
  校验器要求 `<category>-<slug>.md` 与「记录 ID / 试卷 ID」逐字一致：`errors:back-west-spacing` 必须写在
  `errors-back-west-spacing.md`。
- 主题相同就复用同一文件：只要本轮焦点与既有文件的记录 ID 或 slug 主题相同、互为包含关系，就必须追加到该文件，
  不得按日期、轮次或「换了一种练法」另建新文件。
- 记录移动到 `mastered-learning-records/` 后 `id` 不变，继续写同一个文件；只有记录 ID 真正变化时才另建文件。
- 区块标题用 `date '+%Y-%m-%d %H:%M'` 取本轮结束时的本地时间；它只标记**这一轮从哪天开始**，不是「今天」的日期。
- **只有开启新一轮才建新日期区块**：`practice` 抽题、`review` 复习、套题这几类本轮有作答的起点各建一个日期区块。菜单里继续做的习题练习属于同一轮（最多跨几天），一律追加到文件里**最新那个日期区块**，不按今天的日期另建区块；
  区块标题保持本轮开始那天的时间，只把 `笔记更新时间` 刷成本次写入的分钟。跨天再练同一菜单项时同样进这个区块：同一标题小节不重复新建，用 `append-part` 往该小节末尾补这一轮的题目。
- 笔记里不写 `claim_owner`、`claim_token`、临时 payload 路径或其他会话内凭据。

## 分支参考文件

本文件只保留「写到哪、必写栏、模板骨架」这些每次写笔记都要用的口径。下面两类细则按需读取，规则只在子文件里维护一份：

| 触发情况 | 读取 |
|---|---|
| 手动追加区块、补小节、补一段原文，或改写已写错的内容 | `references/note-format-append.md` |
| 跑校验、修派生索引、处理历史迁移 | `references/note-format-validation.md` |

笔记的**唯一**写入方式是脚本命令（`note.py`，或 `learning_records.py review-round` 的 `note` 段），禁止用 `Write` 改写笔记文件。

## 模板结构

唯一格式来源是 `take-english-study-notes/templates/review-note.md`：只允许替换 `<…>` 占位符，
不得新增、删除、重排任何标题、字段、空行、列表符号或标记，也不得自创 `## 追踪` 这类错层标题。
文件最顶部放**全文件唯一一份**的 `## 基础信息` 二级标题（用作导航）与紧随其后的追踪表，承载与单次复习无关的记录级字段；
每个日期标题下先写该轮的题组标题：题目没有菜单项标题时用兜底标题 `## 本轮习题`，题目本身带菜单项标题（如「练习「…」的关键语法结构」）时直接写该标题、不写 `## 本轮习题`。本轮追踪表紧跟在这个题组标题之下、第一题之前（表格本身**不加小标题**）；同一区块里另有带习题的菜单项小节时，那些小节只写自己的两行表（`本轮得分` / `题量与错题数`），再写第一题。只记这一轮发生过什么。基础信息与讲解两处都**固定展示、不折叠**，不要写 `<details>`。

固定骨架：

| 层级 | 固定写法 |
|---|---|
| 文件开头 | 先写 `## 基础信息` 二级标题与追踪表（整个文件唯一一份）；讲解笔记接着写 `## 讲解`，需要时再写只讲解、不带习题的菜单小节；之后才是第一个 `# <YYYY-MM-DD HH:MM> · 复习` 区块（kind 换成 `练习` 或 `套题`）；全文件只有日期这一类一级标题 |
| 轮次区块 | `# <YYYY-MM-DD HH:MM> · <复习 / 练习 / 套题 之一>`；两个以上区块之间必须有一行 `---`，文件末尾不写分隔符；区块按时间倒序排列（最新一轮在最前，旧区块依次在后），一轮一个标题 |
| 讲解小节 | `## 讲解` 是整个文件唯一一份、固定展示（不折叠）、必须位于基础信息表之后与所有日期区块之前；只写讲解正文，不写 `讲解时间` / `分类 · 状态变化` / `本轮得分` / `题量与错题数` 等本轮字段，也不写 `## 本轮习题` |
| 讲解正文 | 用 `**<栏目>**：` 分栏，**栏目按本记录的分类选取、不固定、不要求凑齐**：一份笔记只讲自己这一层，跨分类的内容留在对应分类的文件里；至少两栏，每栏内容写成列表或表格，标签后不留空 |
| 各分类必写栏 | `phrases` → `**核心含义**：`；`grammar` → `**语法机制**：`；`usage` → `**语气与语域**：`；`vocabulary` → `**核心含义**：`；`errors` → `**错误机制**：`（校验器按文件名分类核对，缺这一栏直接报错） |
| 各分类建议栏 | `phrases`：核心含义 / 使用场景与语气 / 结构与搭配 / 历史文化背景 / 发音 / 容易混淆 / 可迁移表达；`grammar`：语法机制 / 结构拆解 / 与相近结构对照 / 常见误用 / 可迁移句型（**不写历史文化背景与发音**，对语法没有解释力）；`usage`：核心含义 / 语气与语域 / 使用场景 / 历史文化背景 / 容易混淆 / 可迁移表达；`vocabulary`：核心含义 / 搭配 / 近义辨析 / 历史文化背景 / 发音 / 可迁移表达；`errors`：错误机制 / 为什么错 / 正确表达 / 可迁移表达 |
| 基础信息区 | 文件最顶部、**整个文件唯一一份**、固定展示：`## 基础信息` → 空行 → `<table style="border-collapse:collapse;width:auto">` → `<colgroup><col width="150"><col></colgroup>` → 6 行 → `</table>`，之后空一行接第一个日期标题；不要包进 `<details>` |
| 基础信息字段顺序 | 记录 ID / 试卷 ID → 目标知识点 → 累计复习次数 → 下次复习 → 笔记生成时间 → 笔记更新时间（全部是与单次复习无关的记录级字段） |
| 本轮信息区 | 日期标题下**先写题组标题**（兜底 `## 本轮习题`，或有菜单项标题的 `## <选项原文>`），再在其下写追踪表；表格位于该标题与第一题之间，不折叠、不加小标题 |
| 本轮信息表 | 写在本轮信息区、不写表头：`<table style="border-collapse:collapse;width:auto">` → `<colgroup><col width="150"><col></colgroup>` → 4 行 `<tr><td>字段</td><td>值</td></tr>`（套题 5 行） → `</table>` |
| 本轮字段顺序 | 复习时间 → 分类 · 状态变化 → 本轮得分 → 题量与错题数；**`主观题得分` 只属于套题**，紧跟「题量与错题数」之后，「复习 / 练习」不得写这一行 |
| 复习时间 | `YYYY-MM-DD HH:MM`，必须与轮次标题的时间完全一致（标题写 `# 2026-11-08 21:00 · 复习`，本行就写 `2026-11-08 21:00`） |
| 习题区 | 区块的第一个二级标题就是该轮题组标题：`## 本轮习题` 兜住没有菜单项标题的题组（随机抽题、综合复习入口），其下先放本轮信息表、再每题一个 `### <n>. <题型>`；题目自带菜单项标题时（练习方向、错题聚类等带标题的题组）该标题直接取代 `## 本轮习题`，信息表与题目都写在它之下，此时区块内不出现 `## 本轮习题`。题号从 `1` 连续递增；任何区块（复习 / 练习 / 套题）都至少要有一道题，`## 本轮习题` 只要出现就必须有题目，不允许只放信息表；讲解小节不写习题区 |
| 每题字段 | 依次 `**题目**：` → `**我的答案**：` → `**判定**：`，字段之间空一行 |
| 题内编号 | 选项、多个待判断句、要点手写编号时**顶格写** `1.`，不要写成 `- 1.` / `* 1.` / `- 1)`：Markdown 会把编号渲染成无序列表里再套一层有序列表，校验器会报错 |
| 判定标记 | 只允许 `✅ 正确`、`⚠️ 部分正确`、`❌ 错误`、`⚠️ 未作答`，可在括号内补一句短说明 |
| 题型 | 只允许：单项选择 / 填空 / 改错 / 改写 / 翻译 / 语境判断 / 造句 / 短写作 / 综合运用 |
| 知识点折叠块 | **每道题都必须有**（套题可按 Passage/Part 合并，见「内容要求」），且必须是本题第一个折叠块：`<details>` + `<summary>知识点讲解</summary>`；块内固定四步 `1. **本题知识点**：` `2. **规则与机制**：` `3. **英语的表达逻辑**：` `4. **可迁移表达**：`；答对的题同样要写 |
| 错题折叠块 | 判定位含错误或未作答的题，在知识点讲解之后再写 `<details>`，summary 写 `错题讲解`；同一题多处错误时按序写 `错题讲解 1`、`错题讲解 2`…；块内固定四步 `1. **考点**：` `2. **为什么错**：` `3. **英语的表达逻辑**：` `4. **正确表达**：` |
| 未作答的错题块 | `⚠️ 未作答` 的题同样写 `错题讲解` 块，第 2 步标签换成 `2. **为什么答不出**：` |
| 菜单项讲解区（文件级） | 只有讲解、不带习题的菜单项，以及带习题菜单项的 `**讲解要点**：`，一律写在 `## 讲解` 之后、所有日期区块之前，以 `## <用户选中的菜单项原文，去掉 emoji>` 作二级标题（与 `## 讲解` 同级）；其下只写**一组** `**讲解要点**：`：每行一条要点，每条要点下面用两个空格缩进的子项写支撑它的**一个或多个可迁移表达 / 例句 / demo**，每句英文后附中文翻译（`  - I joined a studio after graduation.`（毕业后我加入了一家工作室））；不再另起 `**可迁移表达**：` 字段。写入用 `append-explain-section` |
| 日期区块内的菜单项 | 只有**带习题**的菜单项才在日期区块里建小节，标题与该菜单项的文件级小节同名；小节内**只写习题**（先写两行表 `本轮得分` / `题量与错题数`，再写 `### <n>. <题型>`、题目、我的答案、判定、知识点讲解 / 错题讲解折叠块），不再重复 `**讲解要点**：`。写入用 `append-section`，不要为加一节整块 `replace`；同一菜单项再选一次只追加新习题，不追讲解 |
| 菜单项重复选择 | 讲解只写首轮一次：同一菜单项被选第二遍时不再改动文件级小节，只在日期区块补这一轮的习题。场景对话与小故事例外：每次都要追加完整原文，用 `append-explain-part` 追加到同一小节末尾，第二段起编号为 `场景对话原文 1 / 2`、`故事原文 1 / 2`；不带习题的对比类小节记录过一次后不再记录 |
| 同一天多次练同一菜单项 | 日期标题**不变**（仍是 `# <YYYY-MM-DD HH:MM> · <复习 / 练习 / 套题>`，不加后缀；跨天往同一区块追加同理，日期永远是本轮开始那天）；同一天落在多个区块里时，这些区块算同一个「天组」，同一菜单项的习题小节从第 2 份起统一编号：最早那份 `## <选项原文> - 01`、下一份 ` - 02`……按时间升序连续；当天只有一份时**不加后缀**。写入命令（`append` / `append-section`）自动补号并把已有那份改成 ` - 01`；同一轮隔天再练时进的是同一个区块、同一个「天组」，重复的菜单项用 `append-part` 并入既有小节，不会再出现第二份同标题小节；校验器核对单份不得带后缀、多份必须 ` - 01` 起连续，`--fix` 能自动补 / 去后缀 |
| 菜单项折叠块 | 只有一份原文时 summary 写 `<summary>场景对话原文</summary>` / `<summary>故事原文</summary>`，**不要编号**，也不要在块前写 `**完整场景对话**：`、`**故事原文**：` 这类标签行；同一小节出现第二份原文起，第一份改成 `场景对话原文 1` / `故事原文 1`，其余按出现顺序 `2`、`3`… 连续编号。`scenario-dialogue` 每块至少 4 句台词；`focus-story` 每块保留完整英文叙事（至少 8 句）且每个英文段落后面紧跟一行中文译文，收尾三列表（`故事里的位置` / `当时想表达什么` / `为什么不换别的表达`）折叠在**同一个故事原文块内**、写在叙事与译文之后，多段故事每段各带一张表 |

## 追踪字段取值

### 文件级「基础信息」

| 字段 | 允许的写法 |
|---|---|
| 记录 ID / 试卷 ID | `<category>:<key>` 或试卷 `paper_id`；须与文件名一致 |
| 目标知识点 | 记录 `title` |
| 累计复习次数 | 数字，未评分 `—` |
| 下次复习 | `YYYY-MM-DD HH:MM`，未知 `—` |
| 笔记生成时间 | `YYYY-MM-DD HH:MM`；文件第一次写入的时间，之后不再变 |
| 笔记更新时间 | `YYYY-MM-DD HH:MM`；每次追加或替换后改成本次操作分钟，必须不早于 `笔记生成时间` |

`累计复习次数` 与 `下次复习` 属于记录级字段，值由规范记录决定：写入命令在 `append` / `replace` / `sync --check`
之后用 `learning_records.py record-tracking --id <id>` 取回期望值，把它们自动回填成记录的值（返回 `basic_info_synced`），
不需要也不允许调用方手抄。`append` / `replace` 只落日期区块，不会顺带改这张表，所以已有笔记的旧值要么等下一次写入自动纠正，
要么直接用 `note.py sync --file <笔记文件>` 就地修复。身份行（记录 ID / 目标知识点）与其余本轮字段不由同步覆盖，
不一致仍然返回 `tracking_mismatch` / `tracking_expected`。

### 每轮「本轮信息」

讲解小节没有任何追踪字段：它属于记录级内容（一个知识点只有一次首次讲解），只有日期区块才写下面这些行。

| 字段 | 允许的写法 |
|---|---|
| 复习时间 | `YYYY-MM-DD HH:MM`，与该轮标题时间一致 |
| 分类 · 状态变化 | `<category> · <旧状态> → <新状态>`；没有写入规范记录的练习写 `<category> · 未入库`；纯展示、没有题组的轮次写 `<category> · 未评分` |
| 本轮得分 | `x / 10`、`xxx / 710（无听力模拟折算分）`、未评分 `—`；保存失败且已放弃写 `评分未保存（已放弃）` |
| 题量与错题数 | `N 题 / M 处错误`；有未作答时补 `（另有 K 题未作答）` |
| 主观题得分 | **仅套题写这一行**：`写作 x/15 · 翻译 x/15`；`复习` / `练习` 整行不写，校验器会按 kind 判断行数 |

### 每轮「菜单小节信息」

带习题的菜单项小节在自己的标题下写一张两行表（不加小标题、不折叠），字段固定：

| 字段 | 允许的写法 |
|---|---|
| 本轮得分 | `x / 10`，该小节题组的 0 至 10 分；这些练习只写笔记，不写规范记录 |
| 题量与错题数 | `N 题 / M 处错误`；有未作答时补 `（另有 K 题未作答）` |

这两行由校验器核对：`N` 必须等于该小节内实际题目数，`M` 必须等于该小节内实际写出的 `错题讲解` 块数
（判错、部分正确都算，**未作答 / 未完成 / 漏答 不算**），`K` 必须等于该小节实际判为未作答的题数。
历史小节没有这两行时校验器不拦（当时没有计分口径），新写入必须带上。

`题量与错题数` 由校验器核对：`N` 必须等于该轮题组小节（`## 本轮习题` 或带菜单项标题的题组小节）内实际题目数，`M` 必须等于实际写出的 `错题讲解` 块数
（判错、部分正确都算，**未作答 / 未完成 / 漏答 不算**），`K` 必须等于实际判为未作答的题数。
`M` 与写入 `errors` 的条数允许不同：属于目标知识点的错误计入扣分但不单独入库，独立错误才入 `errors`。

## 内容要求

- **版式必须渲染后分行**：选项、小题、多行答案一律用列表项（`- A. …`、`- (a) …`、`- (1) …`），
  禁止 `A. … B. … C. … D. …` 挤在同一段。
- `我的答案` 只写该题答案本身：去掉用户提交时的题号前缀与列表标记（`1. B`、`1) B`、`（1）B` 都记 `B`）；
  多题合并提交时按题号拆分，每道题只保留属于自己的内容，其余拼写和标点原样保留。不得为空，未作答写「不会」等实际回复。
- 每道题都必须写 `知识点讲解` 折叠块，可以超出当前复习知识点；答对的题也要写，不能因为正确就省略。
  唯一例外是套题按 Passage/Part 合并讲解：同一段阅读或同一个 Part 只由该段第一题写折叠块，其余题在该位置写一行
  `**知识点**：同第 <n> 题`（`n` 必须是本节内更早、且真的写了 `知识点讲解` 的题号），校验器会核对指向。
- 完全正确的题只写 `知识点讲解`；错题和带可复用错误的题在知识点讲解之后再写 `错题讲解`，只讲本轮实际出现并已讲解过的错误。
- 未作答题同样先写 `知识点讲解`，再写一个 `错题讲解` 块（第 2 步写 `为什么答不出`），给出参考表达与卡点机制；
  不允许只留一行「未作答」而没有讲解。
- 套题同样使用上面的固定骨架：每题一个 `### <n>. <题型>`（写作记 `短写作`、翻译记 `翻译`），不额外加 Part 小标题。
  **按 Passage/Part 合并 `知识点讲解`**：每段阅读只在段内第一题写完整四步折叠块，同段其余题写 `**知识点**：同第 <n> 题`
  指向它；写作与翻译各自独立写块。这样 57 题的套题不会膨胀成 57 份重复讲解。`主观题得分` 填
  `写作 x/15 · 翻译 x/15`，`本轮得分` 填 `xxx / 710（无听力模拟折算分）`。套题笔记因此会明显长于普通复习，
  这是规则要求的结果，不要为了控制篇幅删减知识点讲解。
- **所有内容都结构化记录，禁止整段文字**：分点的讲解、要点、规则、对比结论一律写成有序列表、无序列表或表格，
  一个子点一行；练习作答按习题区模板逐题展开，不要退化成只留「题号 / 题型 / 判定」的汇总表。
- **示范英文一律附中文翻译**：`## 讲解` 各栏的例句、`## <菜单项>` 里「讲解要点」子项的例句 / demo、折叠块里的
  `可迁移表达` 与 `正确表达`，英文句子后都要紧跟中文全角括号译文（`I joined a studio after graduation.`（毕业后我加入了一家工作室））；
  题型名、题目原句、选项、用户答案和 `home-cooked` 这类语言点名称本身不翻译。
- 这条只约束**新写入或本轮改写的区块**，不回溯改造历史笔记：旧笔记里的英文例句缺译文时照原样保留，
  不要为了套规则批量补译、重排或改动历史讲解。

## 菜单项写什么

用户在题组结束后通过数字菜单继续学习时，先判断这一项产出了什么，再决定写到哪里：

- **讲解型（不带习题）**：`follow-up-learning` 的语法/词汇扩展、`scenario-dialogue` 的场景对话、`focus-story` 的小故事、
  `error-clusters` 的专题讲解、对比相近表达等，写成 `## 讲解` 之后的文件级小节（`append-explain-section`），不进日期区块。
- **带习题的选择**：文件级小节只写 `**讲解要点**`（第一轮写一次），本轮实际作答的题目写进日期区块里同名的小节
  （`append-section`），格式与本轮习题完全一致：`### <n>. <题型>`、`**题目**`（必须完整抄写原题，含全部选项与小题）、
  `**我的答案**`（原样照抄）、`**判定**`、`知识点讲解` 折叠块（错题再加 `错题讲解`）。
- **重复选择**：除场景对话与小故事外，同一菜单项不再重复记录——`append-explain-section` 返回 `duplicate: true`
  就停手，不要改名绕过；后续只把这一轮的新习题追加到日期区块。
- `scenario-dialogue` / `focus-story` 每选中一次都要落一份完整原文：第一次写文件级小节，第二次起用
  `append-explain-part` 追加到同一小节；只有一份原文时 summary 写 `场景对话原文` / `故事原文`，出现第二份后
  改成 `场景对话原文 1 / 2`、`故事原文 1 / 2`，块前不写任何标签行。
- `focus-story` 小节每段故事：块内逐段写英文叙事、每段后紧跟一行中文译文，收尾三列表同样写在这个块内（叙事与译文之后），不放到 `</details>` 外面。
  只写讲解要点、不保留故事原文，等于这一段没有交付。
- 只记要点，不抄整段讲解原文；标题直接写用户选中的选项原文（去掉 emoji，不加编号和 `菜单：` 前缀）。
- **会切换题组的选项不记在本轮区块里**：`continue-review`、`review-path`、`familiar-review`、`mastered-review`、
  `explain-current-exercise`、`mastered-exam-paper`、`paper-history`、`continue-paper-attempt`、`retry-random-paper`
  开启的是新一轮，按新一轮自己的日期区块记录。
- 纯导航与查询（`status` 统计、重新打开菜单、`history`）不写。
- 本轮没有选择任何讲解型菜单项时，不追加菜单小节，也不要在习题后留空小节。
