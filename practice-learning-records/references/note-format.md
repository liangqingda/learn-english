# 复习笔记格式与写入规则

本文件是 `learning-record-notes/` 笔记的**唯一规则来源**；`SKILL.md`、`README.md`、`learning-record-notes/README.md`
只做指引，不再复述细则。版式本身以 `practice-learning-records/templates/review-note.md` 为准，校验规则由
`practice-learning-records/scripts/check_note.py` 强制执行。三处冲突时按「模板 → 校验器 → 本文件」的顺序取用。

## 何时写、写到哪

- 复习 / 练习 / 套题笔记只在用户已经提交答案、且评分与错题保存成功（或用户明确放弃保存）之后写；未作答的题组、
  纯菜单、`stats` / `history` / `paper-get` 查询、`next-review` 领取阶段都不写文件。
- 讲解笔记由 `learn-from-english` 在首次讲解后写：本轮实质讲解的每条记录各写一份，区块 kind 为 `讲解`，
  之后这条记录的每次复习继续追加到同一个文件（`note-append` 会按记录 ID 自动定位已存在的文件）。
  讲解区块只写讲解正文，不写本轮得分与题量与错题数，也不写 `## 本轮习题`。
- 保存失败时只在当前对话保留内容，不落盘；用户明确放弃保存后仍写笔记，但追踪字段标注「评分未保存（已放弃）」。
- 一轮复习只写一个文件；分段提交答案时只在最终评分结束时写一次完整版本。套题按整套写一个文件，不按 Part 拆分。
- 同一个记录反复复习会**持续改写同一个文件**：每轮追加一个日期区块，同一轮内的修改（补错题讲解、补场景对话原文、追加菜单项）用 `replace` 就地替换该区块。
  因此区块内同时保留两个时间：`笔记生成时间` 只记首次写入，`笔记更新时间` 记该区块最后一次修改，两者相同时说明写过之后没再改。
- 未评分的作答同样写笔记（`error-clusters` 专题练习、`follow-up-learning` 练习、用户明确参与并出现作答的场景对话），
  追踪字段的「本轮得分」与「分类 · 状态变化」写 `—` 与 `<category> · 未评分`，不调用 `complete-review`。
- 文件名不带日期：`learning-record-notes/<category>-<slug>.md`。`category` 取 `vocabulary`、`phrases`、`grammar`、
  `usage`、`errors`；套题用 `paper`；`mixed` **仅**用于一次练习同时实质考查 ≥2 个分类的情况，其余一律用锚点记录所在分类，
  禁止 `misc`、`practice` 等自造前缀。
- `slug` 取记录 `id` 或 `paper_id` 的语义部分，只保留小写字母、数字、连字符；记录 `id` 本身含中文时（如
  `usage:after-不宜直接当-later-连接后续动作`）slug 必须原样带上中文，不得自行翻译成英文别名。
  校验器要求 `<category>-<slug>.md` 与「记录 ID / 试卷 ID」逐字一致：`errors:back-west-spacing` 必须写在
  `errors-back-west-spacing.md`。
- 主题相同就复用同一文件：只要本轮焦点与既有文件的记录 ID 或 slug 主题相同、互为包含关系，就必须追加到该文件，
  不得按日期、轮次或「换了一种练法」另建新文件。
- 记录移动到 `mastered-learning-records/` 后 `id` 不变，继续写同一个文件；只有记录 ID 真正变化时才另建文件。
- 区块标题用 `date '+%Y-%m-%d %H:%M'` 取本轮结束时的本地时间。
- 笔记里不写 `claim_owner`、`claim_token`、临时 payload 路径或其他会话内凭据。

## 追加与修正

笔记的**唯一**写入方式是脚本命令，禁止用 `Write` 改写笔记文件。统一入口是本 skill 自带的
`practice-learning-records/scripts/note.py`：它把 `append` / `append-section` / `replace` 转发给 `learn-from-english` 的
`learning_records.py`（先看 `$LEARN_ENGLISH_CLI`，再看仓库内同级目录与安装位），`check` 则直接用本 skill 的
`check_note.py`，因此只装任一 skill 时都能定位到自己需要的那一半。

1. 用 heredoc 把本轮区块通过标准输入传给命令，**不要**先写固定路径的临时文件（如 `/tmp/note-block.md`）；
   确需文件时用 `mktemp`。区块第一行必须是 `# <YYYY-MM-DD HH:MM> · <讲解|复习|练习|套题>`，一个区块只能有一个标题行。
2. 追加：
   ```bash
   python3 practice-learning-records/scripts/note.py append \
     --file learning-record-notes/<category>-<slug>.md \
     --content-file - --check <<'EOF'
   # <YYYY-MM-DD HH:MM> · 复习
   …本轮区块全文…
   EOF
   ```
3. 命令在 `learning-record-notes/.notes.lock` 上取排他锁，锁内完成「读现有文件 → 补 `---` 分隔 → 原子替换」。
4. 返回值语义：
   - `appended: true, heading_adjusted: false`：正常写入。
   - `appended: true, heading_adjusted: true`：这一分钟已被另一轮占用，或直接写入会打乱时间升序，
     **本轮已用顺延后的分钟保存**，`heading` 是实际写入的标题，`requested_heading` 是原请求；
     两轮内容都保留，按 `heading` 继续后续修正。
   - `appended: false, duplicate: true`：该标题的**同样内容**已存在（重试或并发冲突的产物），按已写入处理，
     不要重试、不要手工补写。
5. 追加菜单小节（例如「场景对话」「对比相近表达」）：用**追加小节**命令，锁内只把这一节塞进既有区块，
   区块其余内容一字不动；**不要**为了加一节而整块 `replace`。
   ```bash
   python3 practice-learning-records/scripts/note.py append-section \
     --file learning-record-notes/<category>-<slug>.md \
     --heading "# <目标区块标题>" \
     --content-file - --check <<'EOF'
   ## <菜单项原文>
   …本节讲解与习题…
   EOF
   ```
   - 内容必须以 `## ` 开头、不能含一级标题；目标标题必须与文件里已有区块完全一致。
   - `appended_section: true`：已追加。`duplicate: true`：同一标题同一内容已经在区块里，按已写入处理，不要重试。
   - 报 `section … already exists in this block` 时说明同标题小节已存在且内容不同：改用 `replace` 修正整块，
     不要追加第二个同标题小节。
6. 本轮区块刚写错时才用替换命令（同样走 stdin，标题行必须与追加时返回的 `heading` 完全一致）；
   写入命令会自动把 `笔记更新时间` 刷成本次写入的分钟（追加、区块替换、追加小节都算），不要手工改这一行：
   ```bash
   python3 practice-learning-records/scripts/note.py replace \
     --file learning-record-notes/<category>-<slug>.md \
     --heading "# <本轮标题>" \
     --content-file - --check <<'EOF'
   # <本轮标题>
   …修正后的本轮区块全文…
   EOF
   ```
   替换是整块覆盖，但命令在锁内做了兜底：凡是新内容没有带上、而文件里已经存在的 `## ` 小节，都会被原样保留在
   区块末尾，并在返回值 `preserved_sections` 里列出（这些是别的对话的成果，不要手工删）。只有用
   `--drop-section "## <小节标题>"`（可重复）显式列出的小节才允许真的删除。
   替换一次只允许改**一个**小结：新内容同时改了两个及以上既有小节时命令直接拒绝（避免范围写宽的替换吃掉整段内容），批量迁移要对每个小节逐个加 `--rewrite-section "## <小节标题>"`，返回值 `modified_sections` 列出实际被改写的小节。
   只改一个日期区块，其他日期区块原样保留；不要在标题重复或指向不明时替换。
   改小节正文时必须用锚点收边（下一个 `##` / `###` / `**完整场景对话**：`），并核对 `<details>` / `</details>` 成对、原有小节一个没少；写完同一轮跑 `check --all`。

7. 新建文件同样走追加命令：第一个区块**必须**在标题行之前带上 `## 基础信息` 与追踪表，命令会把它写到文件最顶部；
   写入已有文件时同一次调用里多带的 `## 基础信息` 会被自动忽略，不会重复落地。缺这一段时创建新文件会被直接拒绝。
8. `--check` 的结果在返回 JSON 的 `check` 字段，同时给出 `check_ok` 与 `note_status`：
   - `note_status: "valid"`：笔记合规。
   - `note_status: "invalid"`：写入已成功但笔记不合规（进程退出码 1）。按 issue 的 `line` / `message` 用替换命令就地修正，
     再重跑一次；**不要**把退出码 1 当成写入失败去重试追加。
   - `note_status: "unverified"`：校验器不可用，未执行校验；在回复里如实说明「本轮笔记未校验」，不要当作通过。

## 模板结构

唯一格式来源是 `practice-learning-records/templates/review-note.md`：只允许替换 `<…>` 占位符，
不得新增、删除、重排任何标题、字段、空行、列表符号或标记，也不得自创 `## 追踪` 这类错层标题。
文件最顶部放**全文件唯一一份**的 `## 基础信息` 二级标题（用作导航）与紧随其后的追踪表，承载与单次复习无关的记录级字段；
每个日期标题下**不写任何小标题**，空一行直接放本轮追踪表，只记这一轮发生过什么。两处都**固定展示、不折叠**，不要写 `<details>`。

固定骨架：

| 层级 | 固定写法 |
|---|---|
| 文件开头 | 先写 `## 基础信息` 二级标题与追踪表（整个文件唯一一份），再接第一个 `# <YYYY-MM-DD HH:MM> · 复习` 区块（kind 换成 `练习` 或 `套题`）；全文件只有日期这一类一级标题 |
| 轮次区块 | `# <YYYY-MM-DD HH:MM> · <讲解 / 复习 / 练习 / 套题 之一>`；两个以上区块之间必须有一行 `---`，文件末尾不写分隔符；区块按时间从早到晚排列，一轮一个标题 |
| 基础信息区 | 文件最顶部、**整个文件唯一一份**、固定展示：`## 基础信息` → 空行 → `<table style="border-collapse:collapse;width:auto">` → `<colgroup><col width="150"><col></colgroup>` → 6 行 → `</table>`，之后空一行接第一个日期标题；不要包进 `<details>` |
| 基础信息字段顺序 | 记录 ID / 试卷 ID → 目标知识点 → 累计复习次数 → 下次复习 → 笔记生成时间 → 笔记更新时间（全部是与单次复习无关的记录级字段） |
| 本轮信息区 | 日期标题下不写小标题，空一行直接写追踪表；`## 本轮习题` 是该区块**第一个**二级标题，紧跟表格之后；表格不折叠 |
| 本轮信息表 | 写在本轮信息区、不写表头：`<table style="border-collapse:collapse;width:auto">` → `<colgroup><col width="150"><col></colgroup>` → 4 行 `<tr><td>字段</td><td>值</td></tr>`（套题 5 行） → `</table>` |
| 本轮字段顺序 | 复习时间 → 分类 · 状态变化 → 本轮得分 → 题量与错题数；**`主观题得分` 只属于套题**，紧跟「题量与错题数」之后，「复习 / 练习」不得写这一行；**讲解区块只写 `讲解时间` 与 `分类 · 状态变化` 两行**（分类行写 `<category> · 新学`） |
| 复习时间 | `YYYY-MM-DD HH:MM`，必须与轮次标题的时间完全一致（标题写 `# 2026-11-08 21:00 · 复习`，本行就写 `2026-11-08 21:00`） |
| 习题区 | `## 本轮习题` 是复习 / 练习 / 套题区块内第一个二级标题、紧跟追踪表之后，每题一个 `### <n>. <题型>`，题号从 `1` 连续递增；讲解区块第一个二级标题是 `## 讲解正文`，不写习题区 |
| 每题字段 | 依次 `**题目**：` → `**我的答案**：` → `**判定**：`，字段之间空一行 |
| 题内编号 | 选项、多个待判断句、要点手写编号时**顶格写** `1.`，不要写成 `- 1.` / `* 1.` / `- 1)`：Markdown 会把编号渲染成无序列表里再套一层有序列表，校验器会报错 |
| 判定标记 | 只允许 `✅ 正确`、`⚠️ 部分正确`、`❌ 错误`、`⚠️ 未作答`，可在括号内补一句短说明 |
| 题型 | 只允许：单项选择 / 填空 / 改错 / 改写 / 翻译 / 语境判断 / 造句 / 短写作 / 综合运用 |
| 知识点折叠块 | **每道题都必须有**（套题可按 Passage/Part 合并，见「内容要求」），且必须是本题第一个折叠块：`<details>` + `<summary>知识点讲解</summary>`；块内固定四步 `1. **本题知识点**：` `2. **规则与机制**：` `3. **英语的表达逻辑**：` `4. **可迁移表达**：`；答对的题同样要写 |
| 错题折叠块 | 判定位含错误或未作答的题，在知识点讲解之后再写 `<details>`，summary 写 `错题讲解`；同一题多处错误时按序写 `错题讲解 1`、`错题讲解 2`…；块内固定四步 `1. **考点**：` `2. **为什么错**：` `3. **英语的表达逻辑**：` `4. **正确表达**：` |
| 未作答的错题块 | `⚠️ 未作答` 的题同样写 `错题讲解` 块，第 2 步标签换成 `2. **为什么答不出**：` |
| 菜单项 | 放在 `## 本轮习题` 之后，不写 `菜单与讲解` 小节：每条直接以 `## <用户选中的菜单项原文，去掉 emoji>` 作标题（与 `## 本轮习题` 同为二级），其下只写**一组** `**讲解要点**：`：每行一条要点，每条要点下面用两个空格缩进的子项写支撑它的**一个或多个可迁移表达 / 例句 / demo**（`  - I joined a studio after graduation.`）；不再另起 `**可迁移表达**：` 字段。其下练习沿用习题区同一套模板，题号在小节内从 `1` 重新开始。写入用 `append-section`，不要为加一节整块 `replace` |

## 追踪字段取值

### 文件级「基础信息」

| 字段 | 允许的写法 |
|---|---|
| 记录 ID / 试卷 ID | `<category>:<key>` 或试卷 `paper_id`；须与文件名一致 |
| 目标知识点 | 记录 `title` |
| 累计复习次数 | 数字，未评分 `—` |
| 下次复习 | `YYYY-MM-DD HH:MM`，未知 `—` |
| 笔记生成时间 | `YYYY-MM-DD HH:MM`；文件第一次写入的时间，之后不再变 |
| 笔记更新时间 | `YYYY-MM-DD HH:MM`；每次追加或替换后改成本次操作分钟，必须不早于 `笔记生成时间` |

### 每轮「本轮信息」

| 字段 | 允许的写法 |
|---|---|
| 复习时间 | `YYYY-MM-DD HH:MM`，与该轮标题时间一致 |
| 分类 · 状态变化 | `<category> · <旧状态> → <新状态>`；未评分写 `<category> · 未评分` |
| 本轮得分 | `x / 10`、`xxx / 710（无听力模拟折算分）`、未评分 `—`；保存失败且已放弃写 `评分未保存（已放弃）` |
| 题量与错题数 | `N 题 / M 处错误`；有未作答时补 `（另有 K 题未作答）` |
| 主观题得分 | **仅套题写这一行**：`写作 x/15 · 翻译 x/15`；`复习` / `练习` 整行不写，校验器会按 kind 判断行数 |

`题量与错题数` 由校验器核对：`N` 必须等于 `## 本轮习题` 内实际题目数，`M` 必须等于实际写出的 `错题讲解` 块数
（判错、部分正确都算，**未作答 / 未完成 / 漏答 不算**），`K` 必须等于实际判为未作答的题数。
`M` 与写入 `errors` 的条数允许不同：属于目标知识点的错误计入扣分但不单独入库，独立错误才入 `errors`。

## 内容要求

- **版式必须渲染后分行**：选项、小题、多行答案一律用列表项（`- A. …`、`- (a) …`、`- (1) …`），
  禁止 `A. … B. … C. … D. …` 挤在同一段。
- `我的答案` 只写该题答案本身：去掉用户提交时的题号前缀与列表标记（`1. B`、`1) B`、`（1）B` 都记 `B`）；
  多题合并提交时按题号拆分，每道题只保留属于自己的内容，其余拼写和标点原样保留。不得为空，未作答写「不会」等实际回复。
- 每道题都必须写 `知识点讲解` 折叠块，可以超出当前复习知识点；答对的题也要写，不能因为正确就省略。
  唯一例外是套题按 Passage/Part 合并讲解：同一段阅读或同一个 Part 只由该段第一题写折叠块，其余题在该位置写一行
  `**知识点**：同第 <n> 题`（`n` 必须是本节内更早、且真的写了 `知识点讲解` 的题号），校验器会核对指向。
- 完全正确的题只写 `知识点讲解`；错题和带可复用错误的题在知识点讲解之后再写 `错题讲解`，只讲本轮实际出现并已讲解过的错误。
- 未作答题同样先写 `知识点讲解`，再写一个 `错题讲解` 块（第 2 步写 `为什么答不出`），给出参考表达与卡点机制；
  不允许只留一行「未作答」而没有讲解。
- 套题同样使用上面的固定骨架：每题一个 `### <n>. <题型>`（写作记 `短写作`、翻译记 `翻译`），不额外加 Part 小标题。
  **按 Passage/Part 合并 `知识点讲解`**：每段阅读只在段内第一题写完整四步折叠块，同段其余题写 `**知识点**：同第 <n> 题`
  指向它；写作与翻译各自独立写块。这样 57 题的套题不会膨胀成 57 份重复讲解。`主观题得分` 填
  `写作 x/15 · 翻译 x/15`，`本轮得分` 填 `xxx / 710（无听力模拟折算分）`。套题笔记因此会明显长于普通复习，
  这是规则要求的结果，不要为了控制篇幅删减知识点讲解。
- **所有内容都结构化记录，禁止整段文字**：分点的讲解、要点、规则、对比结论一律写成有序列表、无序列表或表格，
  一个子点一行；练习作答按习题区模板逐题展开，不要退化成只留「题号 / 题型 / 判定」的汇总表。

## 菜单项写什么

用户在题组结束后通过数字菜单继续学习时，把「选了什么 + 讲到了什么 + 练了什么」追加到**同一个日期区块**习题之后，
以 `## <选项原文>` 与 `## 本轮习题` 同级并列，不另建文件、不另开日期区块：

- 记录讲解型选择：`follow-up-learning` 的语法/词汇扩展、`scenario-dialogue` 的场景对话、`error-clusters` 的专题讲解等，
  凡实际产出了讲解内容的选择都要记。
- 该菜单项随后产生的作答也记在同一处，格式与本轮习题完全一致：`### <n>. <题型>`、`**题目**`（必须完整抄写原题，
  含全部选项与小题）、`**我的答案**`（原样照抄）、`**判定**`、`知识点讲解` 折叠块（错题再加 `错题讲解`）。
- 只记要点，不抄整段讲解原文；标题直接写用户选中的选项原文（去掉 emoji，不加编号和 `菜单：` 前缀），按选择顺序排列。
- **会切换题组的选项不记在本轮区块里**：`continue-review`、`review-path`、`familiar-review`、`mastered-review`、
  `explain-current-exercise`、`mastered-exam-paper`、`paper-history`、`continue-paper-attempt`、`retry-random-paper`
  开启的是新一轮，按新一轮自己的日期区块记录。
- 纯导航与查询（`status` 统计、重新打开菜单、`history`）不写。
- 本轮没有选择任何讲解型菜单项时，不追加菜单标题，也不要在习题后留空小节。

## 校验与历史迁移

写完必须校验通过。`--check` 已自动运行同一条命令，需要单独复查时运行：

```bash
python3 practice-learning-records/scripts/note.py check --all          # 全量校验默认 notes 目录
python3 practice-learning-records/scripts/note.py check --all --fix    # 先修无争议项再校验
python3 practice-learning-records/scripts/note.py check learning-record-notes/<category>-<slug>.md
```

`--all` 用 `$LEARN_ENGLISH_REPO_ROOT`（缺省取本脚本所在仓库根）定位 `learning-record-notes/`，跳过 `README.md`；
CI 每次 push 跑这一条。`--fix` 只处理六类无争议问题：行尾空格、`我的答案` 的题号前缀、缺失的区块 `---` 分隔、
缺失的 `笔记更新时间` 行（按该区块 `笔记生成时间` 补齐）、把记录级字段上移到文件顶部唯一一份 `## 基础信息`、给每轮补 `复习时间` 行、把原先包住两处的 `<details>` 折叠块拆成固定展示（每轮表格不加小标题）、删掉非套题里恒为 `—` 的 `主观题得分` 行，
以及删掉 `基础信息` 与第一个日期区块之间多余的 `---`，
不改题干、讲解、判定与区块顺序；它不需要人工触发——`append` / `replace --check` 发现校验失败时会自动修完再复检，
并用 `auto_fixed` 回传改了什么。追踪字段的身份值（记录 ID、目标知识点、状态变化、本轮得分、累计复习次数、下次复习）
同样由写入命令自动比对，不一致时返回 `tracking_mismatch` 与 `tracking_expected`。

`ok: true` 表示笔记合规。`ok: false` 时按 issue 的 `line` 与 `message` 修正：

- issue 落在本轮刚追加的区块内：把修正后的完整区块交给同一把锁的替换命令就地替换，不要整文件重写、不要追加第二遍。
- issue 落在更早的历史区块内：不借本轮修改历史、不为通过校验重排旧区块；第二次仍不通过时，正常发送批改与讲解正文，
  并在正文里如实说明「本轮笔记未通过校验，已保留待修正」，把 issue 记在当前对话，下一轮优先修正该文件。

模板演进（新增/重命名折叠块、增加字段口径）导致历史笔记不再通过校验时，允许一次性迁移，但必须满足三条：
只做追加块、把折叠块拆成固定展示的裸表格、把记录级字段上移到文件顶部 `## 基础信息` 并给每轮补 `复习时间`、只补齐模板新增的追踪字段行（`笔记更新时间` 按相邻的
`笔记生成时间` 迁移）、或只删掉非套题里恒为 `—` 的 `主观题得分` 行；不得改动题干、`我的答案`、判定、正文讲解与历史顺序；迁移前后用 `git diff`
确认没有正文删除。迁移不适用于日常整理，也不得借此重排旧日期区块。
