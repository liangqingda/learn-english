# 复习笔记格式与写入规则

本文件是 `learning-record-notes/` 笔记的**唯一规则来源**；`SKILL.md`、`README.md`、`learning-record-notes/README.md`
只做指引，不再复述细则。版式本身以 `skills/take-english-study-notes/templates/review-note.md` 为准，校验规则由
`skills/take-english-study-notes/scripts/check_note.py` 强制执行。三处冲突时按「模板 → 校验器 → 本文件」的顺序取用。

## 何时写、写到哪

- 复习 / 练习 / 套题笔记只在用户已经提交答案、且评分与错题保存成功（或用户明确放弃保存）之后写；未作答的题组、
  纯菜单、`stats` / `history` / `paper-get` 查询、`next-review` 领取阶段都不写文件。
- **笔记按需生成，不要求一条记录一份**：记录只有被首次讲解（`note.py explain`）或被抽中复习（`review-round` 的 `note` 段）
  时才落一份笔记文件；`batch-upsert` 只写规范记录、不建笔记。从没被讲解、也没被复习过的记录没有笔记文件属于正常状态，
  `check --all` 会把它们列进 `missing_notes` 只做体检报告、不算校验错误；需要补建时仍用 `note.py explain`。
- **从零重建笔记的固定顺序**（记录仍在、笔记文件不存在时——被 `delete-note --keep-record` 删掉、或被别的会话清理掉——一律按这三步重建，不要跳步）：
  1. `note.py explain` 写 `## 基础信息`（累计复习次数、下次复习由脚本按记录回填）与 `## 讲解`；
  2. 本轮用到了带习题的菜单项、或要补场景对话 / 小故事时，用 `append-explain-section` / `append-explain-part` 写文件级小节；带习题菜单项的 `**讲解要点**` 只写一次，重建时最容易被漏掉，漏了只补这一节（`append-explain-section` 返回 `duplicate: true` 就停手）；
  3. 最后用 `append` 开日期区块、`append-section` 写本轮习题小节。
  直接对不存在的文件跑 `append` / `append-section` 会报 `note does not exist`，那不是“这轮不写笔记”，只是漏了第 1 步。
- 讲解笔记由 `learn-from-english` 在首次讲解后写：本轮实质讲解的每条记录各写一份，用 `note.py explain` 创建。
  讲解是**文件级固定小节** `## 讲解`，紧跟 `## 基础信息` 表格之后、位于所有日期区块之前：一个知识点只有一次首次讲解，
  复习才会多轮，所以讲解不参与轮次编号；之后这条记录的每次复习继续用 `note.py append` 把新日期区块插到同一个文件最前
  （`append` 会按记录 ID 自动定位已存在的文件）。
  一份笔记只有一份 `## 讲解`；文件已存在讲解时 `explain` 返回 `duplicate: true`，不要写第二份。
- 保存失败时只在当前对话保留内容，不落盘；用户明确放弃保存后仍写笔记，但追踪字段标注「评分未保存（已放弃）」。
- 一轮复习只写一个文件；分段提交答案时只在最终评分结束时写一次完整版本。套题按整套写一个文件，不按 Part 拆分。
- 同一个记录反复复习会**持续改写同一个文件**：开启新一轮时在最前插入一个日期区块（最新一轮在最上，旧区块依次后移），同一轮内的修改（补错题讲解、补场景对话原文、追加菜单项、隔天再补题组）就地改同一个区块，不新开区块。
  因此区块内同时保留两个时间：`笔记生成时间` 只记首次写入，`笔记更新时间` 记该区块最后一次修改，两者相同时说明写过之后没再改。
- **讲解型内容一律进文件级讲解区，日期区块只放习题**：菜单项里只有「讲解要点 / 对比 / 场景对话 / 小故事」这类内容时，写成
  `## 讲解` 之后的文件级小节；只有该菜单项**带习题**时，才在日期区块里另建一个同名小节并只写习题（题号、题目、答案、判定、讲解折叠块）。
  同一条记录的讲解要点只在第一轮写一次，后续重复选择只往日期区块写习题，不再改动讲解区。
  **带习题的菜单项在讲解区必须有同名文件级小节**：当轮有讲解要点就把要点写进这一节；这一轮纯答题、没有讲解内容时，该文件级小节只保留标题、正文留空，
  由索引重建自动挂上「复习历史」`practice-index` 索引（骨架小节不写 `**讲解要点**：`，属正常状态）。`append-section` 写日期区块习题小节时会自动在讲解区补上这份同名骨架；
  校验器发现日期区块已有习题小节、讲解区却没有同名小节时会报错。
  同一个菜单项被重复选中时，除场景对话与小故事外不再重复记录（例如「对比相近表达」记录过一次后，后续不再新建小节）。
  **带习题的菜单项可以先落盘讲解要点**：讲解当轮就用 `append-explain-section` 把 `**讲解要点**` 写进文件级同名小节
  （这一节还没有习题时不需要 `复习历史` 索引，属正常状态），习题部分仍等用户提交、评分成功后再用 `append-section`
  写进该轮最新的日期区块；这样「只讲解、不答题」的轮次也不会丢掉讲解内容。这一节已存在时再次讲解只用
  `replace --rewrite-section` 就地修正，不新建第二节。
- 场景对话与小故事是例外：每选中一次就要追加一段完整原文，每段都带自己的标题（`<summary>场景对话原文 · <标题></summary>` / `<summary>故事原文 · <标题></summary>`），第二段起按 `场景对话原文 1 · <标题> / 2 · <标题>`、`故事原文 1 · <标题> / 2 · <标题>` 编号；标题就是聊天里这一段正文首行 `**<标题>**` 的文字，两处必须一模一样。
- **对比相近表达、扩展讲解这类小节要把当轮展示的正文完整落进来**：`**讲解要点**` 只是摘要，不能替代正文；
  聊天里给出的对比表、结论清单、句型对照、例句组要原样写进该小节，缺了就等于这一轮内容没有交付，
  与场景对话漏原文、小故事漏原文同一性质。这类正文同样受「一律写成列表或表格」约束，不要压成一段散文。
- 只要本轮有习题，就按 0 至 10 分给出得分，题量与错题数一并记录。复习与套题把得分写进规范记录；
  `follow-up-learning` 练习、`error-clusters` 专题练习、互动角色扮演里用户实际作答的题组同样计分，
  但得分只写进笔记（`本轮得分` 填 `x / 10`、`分类 · 状态变化` 整行不写），不调用 `complete-review`。
  纯展示项（场景对话脚本、小故事、讲解）不产生题组，也就没有本轮得分。
- 笔记按分类分目录存放：`learning-record-notes/<category>/<category>-<slug>.md`，目录名必须等于文件名前缀
  （`errors/errors-out-west.md`、`paper/paper-cet6-xxx.md`）。目录与文件名前缀不一致、或直接放在
  `learning-record-notes/` 根下都会被校验器拒绝；`categories.json` 与 `README.md` 留在根目录。
- 文件名不带日期：`learning-record-notes/<category>/<category>-<slug>.md`。`category` 只能取 `learning-record-notes/categories.json`
  里声明的键（现有 `vocabulary`、`phrases`、`grammar`、`usage`、`errors`；套题用 `paper`）；一轮练习即使实质考查 ≥2 个分类，
  也只写「锚点记录」所在的分类——锚点取本轮错得最多、
  或主要考查的那一条记录，它的记录 ID 就决定文件名；禁止 `mixed`、`misc`、`practice` 等自造前缀。
  写入命令仍接受旧式平铺路径（`learning-record-notes/<category>-<slug>.md`）：`NoteStore.resolve`
  会按文件名前缀算出分类目录，并在第一次写入时把旧文件移进去。
- **分类清单只有一份**：键、中文标题、展示顺序与 `hidden` 都由 `learning-record-notes/categories.json` 定义。
  改标题、调列顺序、把某类从看板藏起来只改这个文件，不要再抄一份到笔记正文、复习菜单或其他项目
  （`my-dashboard` 的英语页直接读它来排看板列）。**新增一个全新分类**除了改该文件，还要新建同名目录
  （`learning-record-notes/<new-key>/`）、同步本节的
  分类列表、`check_note.py` 的分类集合和下面的「各分类必写栏」——校验器靠那里拦自造前缀。
  别处读到的不在清单里的前缀，说明这里是唯一漏改的地方。
- `slug` 取记录 `id` 或 `paper_id` 的语义部分，只保留小写字母、数字、连字符。记录 `key` 与 `slug`
  一律用 ASCII，中文主题必须意译成英文短语（`usage:after-不宜直接当-later-连接后续动作`
  应写成 `usage:after-vs-later-sequence`），不得把中文直接拼进 `key`；`learning_records.py` 会把
  非 ASCII 字符压掉而报 key 无效，`check_note.py` 也会拒收中文文件名。
  校验器要求 `<category>-<slug>.md` 与「记录 ID / 试卷 ID」逐字一致：`errors:back-west-spacing` 必须写在
  `errors-back-west-spacing.md`。
- 主题相同就复用同一文件：只要本轮焦点与既有文件的记录 ID 或 slug 主题相同、互为包含关系，就必须追加到该文件，
  不得按日期、轮次或「换了一种练法」另建新文件。
- 记录移动到 `mastered-learning-records/` 后 `id` 不变，继续写同一个文件；只有记录 ID 真正变化时才另建文件。
- 区块标题用 `date '+%Y-%m-%d %H:%M'` 取本轮结束时的本地时间；它只标记**这一轮从哪天开始**，不是「今天」的日期。笔记里所有时间戳一律 24 小时制 `HH:MM`（小时 `00`–`23`、分钟 `00`–`59`），不写上午/下午、不用 12 小时制。
- **只有开启新一轮才建新日期区块**：`practice` 抽题、`review` 复习、套题这几类本轮有作答的起点各建一个日期区块。菜单里继续做的习题练习属于同一轮（最多跨几天），一律追加到文件里**最新那个日期区块**，不按今天的日期另建区块；
  区块标题保持本轮开始那天的时间，只把 `笔记更新时间` 刷成本次写入的分钟。跨天再练同一菜单项时同样进这个区块：不再并进既有小节，而是按当天序号另建一节（`## <选项原文> - 01`、` - 02`…），一节一表、题号各从 1 起。
- 笔记里不写 `claim_owner`、`claim_token`、临时 payload 路径或其他会话内凭据。

本文件只保留「写到哪、必写栏、模板骨架」这些每次写笔记都要用的口径。下面两类细则按需读取，规则只在子文件里维护一份：

| 触发情况 | 读取 |
|---|---|
| 手动追加区块、补小节、补一段原文，或改写已写错的内容 | `references/note-format-append.md` |
| 跑校验、修派生索引、处理历史迁移 | `references/note-format-validation.md` |

笔记的**唯一**写入方式是脚本命令（`note.py`，或 `learning_records.py review-round` 的 `note` 段），禁止用 `Write` 改写笔记文件。

## 模板结构

唯一格式来源是 `skills/take-english-study-notes/templates/review-note.md`：只允许替换 `<…>` 占位符，
不得新增、删除、重排任何标题、字段、空行、列表符号或标记，也不得自创 `## 追踪` 这类错层标题。
文件最顶部放**全文件唯一一份**的 `## 基础信息` 二级标题（用作导航）与紧随其后的追踪表，承载与单次复习无关的记录级字段；
每个日期标题下先写该轮的题组标题：题目没有菜单项标题时用兜底标题 `## 本轮习题`，题目本身带菜单项标题（如「练习「…」的关键语法结构」）时直接写该标题、不写 `## 本轮习题`。本轮追踪表紧跟在这个题组标题之下、第一题之前（表格本身**不加小标题**）；同一区块里另有带习题的菜单项小节时，那些小节只写自己的三行表（`生成时间` / `本轮得分` / `题量与错题数`），再写第一题。只记这一轮发生过什么。基础信息与讲解两处都**固定展示、不折叠**，不要写 `<details>`。

固定骨架：

| 层级 | 固定写法 |
|---|---|
| 文件开头 | 先写 `## 基础信息` 二级标题与追踪表（整个文件唯一一份）；讲解笔记接着写 `## 讲解`，需要时再写只讲解、不带习题的菜单小节；之后才是第一个 `# <YYYY-MM-DD HH:MM> · 复习` 区块（kind 换成 `练习` 或 `套题`）；全文件只有日期这一类一级标题 |
| 轮次区块 | `# <YYYY-MM-DD HH:MM> · <复习 / 练习 / 套题 之一>`；两个以上区块之间必须有一行 `---`，文件末尾不写分隔符；区块按时间倒序排列（最新一轮在最前，旧区块依次在后），一轮一个标题；区块内的菜单项小节同样按落盘时间倒序排列（最新一节在最前，旧小节依次在后），`## 本轮习题` 若存在则固定为区块内第一个二级标题 |
| 讲解小节 | `## 讲解` 是整个文件唯一一份、固定展示（不折叠）、必须位于基础信息表之后与所有日期区块之前；只写讲解正文，不写 `讲解时间` / `分类 · 状态变化` / `本轮得分` / `题量与错题数` 等本轮字段，也不写 `## 本轮习题` |
| 讲解正文 | 用 `**<栏目>**：` 分栏，**栏目按本记录的分类选取、不固定、不要求凑齐**：一份笔记只讲自己这一层，跨分类的内容留在对应分类的文件里；至少两栏，每栏内容写成列表或表格，标签后不留空 |
| 各分类必写栏 | `phrases` → `**核心含义**：`；`grammar` → `**语法机制**：`；`usage` → `**语气与语域**：`；`vocabulary` → `**核心含义**：`；`errors` → `**错误机制**：`（校验器按文件名分类核对，缺这一栏直接报错） |
| 各分类建议栏 | `phrases`：核心含义 / 使用场景与语气 / 结构与搭配 / 历史文化背景 / 发音 / 容易混淆 / 可迁移表达；`grammar`：语法机制 / 结构拆解 / 与相近结构对照 / 常见误用 / 可迁移句型（**不写历史文化背景与发音**，对语法没有解释力）；`usage`：核心含义 / 语气与语域 / 使用场景 / 历史文化背景 / 容易混淆 / 可迁移表达；`vocabulary`：核心含义 / 搭配 / 近义辨析 / 历史文化背景 / 发音 / 可迁移表达；`errors`：错误机制 / 为什么错 / 正确表达 / 可迁移表达 |
| 基础信息区 | 文件最顶部、**整个文件唯一一份**、固定展示：`## 基础信息` → 空行 → `<table style="border-collapse:collapse;width:auto">` → `<colgroup><col width="150"><col></colgroup>` → 6 行 → `</table>`，之后空一行接第一个日期标题；不要包进 `<details>` |
| 基础信息字段顺序 | 记录 ID / 试卷 ID → 目标知识点 → 累计复习次数 → 下次复习 → 笔记生成时间 → 笔记更新时间（全部是与单次复习无关的记录级字段） |
| 本轮信息区 | 日期标题下**先写题组标题**（兜底 `## 本轮习题`，或有菜单项标题的 `## <选项原文>`），再在其下写追踪表；表格位于该标题与第一题之间，不折叠、不加小标题 |
| 本轮信息表 | 写在本轮信息区、不写表头：`<table style="border-collapse:collapse;width:auto">` → `<colgroup><col width="150"><col></colgroup>` → 4 行 `<tr><td>字段</td><td>值</td></tr>`（套题 5 行） → `</table>` |
| 本轮字段顺序 | 生成时间 → （分类 · 状态变化，仅本轮改了记录状态时才有）→ 本轮得分 → 题量与错题数；**`主观题得分` 只属于套题**，紧跟「题量与错题数」之后，「复习 / 练习」不得写这一行 |
| 生成时间 | `YYYY-MM-DD HH:MM`（24 小时制），这一轮真正写进笔记的时刻，由写入脚本按落盘时间盖；调用方不要手写这一行——首次落盘时手写值会被落盘时刻覆盖；可以不等于轮次标题时间，但不得早于它（标题写 `# 2026-11-08 21:00 · 复习`，本行写 `2026-11-08 21:02` 也合规） |
| 习题区 | 区块的第一个二级标题就是该轮题组标题：`## 本轮习题` 兜住没有菜单项标题的题组（随机抽题、综合复习入口），其下先放本轮信息表、再每题一个 `### <n>. <题型>`；题目自带菜单项标题时（练习方向、错题聚类等带标题的题组）该标题直接取代 `## 本轮习题`，信息表与题目都写在它之下，此时区块内不出现 `## 本轮习题`。题号从 `1` 连续递增；任何区块（复习 / 练习 / 套题）都至少要有一道题，`## 本轮习题` 只要出现就必须有题目，不允许只放信息表；讲解小节不写习题区 |
| 每题字段 | 依次 `**题目**：` → `**我的答案**：` → `**判定**：`，字段之间空一行。`**题目**：` 区只写题干要求、选项与待判断句，**不得把用户提交的答案写进题干**；答案一律只出现在 `**我的答案**：` 区 |
| 题内编号 | 选项、多个待判断句、要点手写编号时**顶格写** `1.`，不要写成 `- 1.` / `* 1.` / `- 1)`：Markdown 会把编号渲染成无序列表里再套一层有序列表，校验器会报错 |
| 判定标记 | 只允许 `✅ 正确`、`⚠️ 部分正确`、`❌ 错误`、`⚠️ 未作答`，可在括号内补一句短说明 |
| 题型 | 只允许：单项选择 / 填空 / 改错 / 改写 / 翻译 / 语境判断 / 造句 / 短写作 / 综合运用 |
| 知识点折叠块 | **每道题都必须有**（套题可按 Passage/Part 合并，见「内容要求」），且必须是本题第一个折叠块：`<details>` + `<summary>知识点讲解</summary>`；块内固定四步无序列表 `- **本题知识点**：` `- **规则与机制**：` `- **英语的表达逻辑**：` `- **可迁移表达**：`，不用 `1. 2. 3. 4.` 有序编号；答对的题同样要写。第 4 步一条例句可跟在标签同行；两条及以上必须逐条写成两个空格缩进的子项（`  - …`），一句一行，不用 `／`、`/` 或 `；` 同行串接；标签行留空、子项写出例句即视为该步有内容 |
| 错题折叠块 | 判定位含错误或未作答的题，在知识点讲解之后再写 `<details>`，summary 写 `错题讲解`；同一题多处错误时按序写 `错题讲解 1`、`错题讲解 2`…；块内固定四步无序列表 `- **考点**：` `- **为什么错**：` `- **英语的表达逻辑**：` `- **正确表达**：`。第 4 步先写纠正后的代表句；另有可迁移例句时逐条缩进成子项，不与代表句同行串接 |
| 未作答的错题块 | `⚠️ 未作答` 的题同样写 `错题讲解` 块，第 2 步标签换成 `- **为什么答不出**：` |
| 菜单项讲解区（文件级） | 只有讲解、不带习题的菜单项，以及带习题菜单项的 `**讲解要点**：`，一律写在 `## 讲解` 之后、所有日期区块之前，以 `## <用户选中的菜单项原文>` 作二级标题（与 `## 讲解` 同级）；其下只写**一组** `**讲解要点**：`：每行一条要点，要点行只写规则或结论；每条要点下面用两个空格缩进的子项写支撑它的**一个或多个可迁移表达 / 例句 / demo**，一句一个子项、每句英文后附中文翻译（`  - I joined a studio after graduation.`（毕业后我加入了一家工作室）），不要把多条例句串在要点行内；不再另起 `**可迁移表达**：` 字段。写入用 `append-explain-section`。纯答题、没有讲解要点的菜单项同样保留一份同名骨架小节：标题之下不写 `**讲解要点**：`，正文留空，只由索引重建挂上「复习历史」`practice-index` 索引 |
| 日期区块内的菜单项 | 只有**带习题**的菜单项才在日期区块里建小节，标题与该菜单项的文件级小节同名；小节内**只写习题**（先写三行表 `生成时间` / `本轮得分` / `题量与错题数`，再写 `### <n>. <题型>`、题目、我的答案、判定、知识点讲解 / 错题讲解折叠块），不再重复 `**讲解要点**：`。写入用 `append-section`，不要为加一节整块 `replace`；`append-section` 会自动在讲解区补建同名骨架小节（讲解要点已写过则复用既有文件级小节）；新小节插在区块最前（`## 本轮习题` 之后、既有菜单项小节之前），区块内小节按落盘时间倒序（新的在前）；同一菜单项再选一次只追加新习题（另建带序号的同标题小节），不追讲解 |
| 菜单项重复选择 | 讲解只写首轮一次：同一菜单项被选第二遍时不再改动文件级小节，只在日期区块补这一轮的习题。场景对话与小故事例外：每次都要追加完整原文，用 `append-explain-part` 追加到同一小节末尾，第二段起编号为 `场景对话原文 1 · <标题> / 2 · <标题>`、`故事原文 1 · <标题> / 2 · <标题>`，标题逐段保留；不带习题的对比类小节记录过一次后不再记录 |
| 同一天多次练同一菜单项 | 日期标题**不变**（仍是 `# <YYYY-MM-DD HH:MM> · <复习 / 练习 / 套题>`，不加后缀；跨天往同一区块追加同理，日期永远是本轮开始那天）；同一天落在多个区块里时，这些区块算同一个「天组」，同一菜单项的习题小节从第 2 份起统一编号：最早那份 `## <选项原文> - 01`、下一份 ` - 02`……按时间升序连续；当天只有一份时**不加后缀**。编号按时间升序（最早 `- 01`），与正文「新的在前」的展示顺序无关：区块最上面的小节可能带最大的后缀号。写入命令（`append` / `append-section`）自动补号并把已有那份改成 ` - 01`；同一轮隔天再练时进的是同一个区块、同一个「天组」，重复的菜单项照样另建一份带序号的同标题小节（一节一表、题号从 1 起），不并入既有小节；校验器核对单份不得带后缀、多份必须 ` - 01` 起连续，`--fix` 能自动补 / 去后缀 |
| 菜单项折叠块 | 每份原文都必须带标题：`<summary>场景对话原文 · <标题></summary>` / `<summary>故事原文 · <标题></summary>`，标题与聊天里这一段正文首行 `**<标题>**` 完全一致（4–16 字的中文场景名，不加引号，不用「场景对话」「小故事」这类泛称）。只有一份原文时**不要编号**，也不要在块前写 `**完整场景对话**：`、`**故事原文**：` 这类标签行；同一小节出现第二份原文起，第一份改成 `场景对话原文 1 · <标题>` / `故事原文 1 · <标题>`，其余按出现顺序 `2`、`3`… 连续编号并各自保留自己的标题。`scenario-dialogue` 每块至少 4 句台词；对话先求日常自然，目标表达只在自然出现的台词上加粗（至少出现一次即可，不必每句重复，其余台词按日常对话正常写），每句英文台词下方缩进一个中文子项：角色名译为中文（Tom → 汤姆），后接该轮台词译文；`focus-story` 每块保留完整英文叙事（至少 8 句），叙事中关键时刻对目标表达加粗，且每个英文段落后面紧跟一行中文译文，收尾三列表（`故事里的位置` / `当时想表达什么` / `为什么不换别的表达`）折叠在**同一个故事原文块内**、写在叙事与译文之后，多段故事每段各带一张表 |

## 追踪字段取值

### 文件级「基础信息」

| 字段 | 允许的写法 |
|---|---|
| 记录 ID / 试卷 ID | `<category>:<key>` 或试卷 `paper_id`；须与文件名一致 |
| 目标知识点 | 记录 `title` |
| 累计复习次数 | 数字，未评分 `—` |
| 下次复习 | `YYYY-MM-DD HH:MM`，未知 `—` |
| 笔记生成时间 | `YYYY-MM-DD HH:MM`（24 小时制）；文件第一次写入的时间，之后不再变 |
| 笔记更新时间 | `YYYY-MM-DD HH:MM`（24 小时制）；每次追加或替换后改成本次操作分钟，必须不早于 `笔记生成时间` |

`累计复习次数` 与 `下次复习` 属于记录级字段，值由规范记录决定：写入命令在 `append` / `replace` / `sync --check`
之后用 `learning_records.py record-tracking --id <id>` 取回期望值，把它们自动回填成记录的值（返回 `basic_info_synced`），
不需要也不允许调用方手抄。`append` / `replace` 只落日期区块，不会顺带改这张表，所以已有笔记的旧值要么等下一次写入自动纠正，
要么直接用 `note.py sync --file <笔记文件>` 就地修复。身份行（记录 ID / 目标知识点）与其余本轮字段不由同步覆盖，
不一致仍然返回 `tracking_mismatch` / `tracking_expected`。

### 每轮「本轮信息」

讲解小节没有任何追踪字段：它属于记录级内容（一个知识点只有一次首次讲解），只有日期区块才写下面这些行。

| 字段 | 允许的写法 |
|---|---|
| 生成时间 | `YYYY-MM-DD HH:MM`（24 小时制），该轮真正写进笔记的时刻；写入脚本盖，不得早于轮次标题时间 |
| 分类 · 状态变化 | 只有本轮真的改了记录状态才写，格式 `<category> · <旧状态> → <新状态>`，两端必须不同；状态没变化（含没评分、得分没进规范记录）整行不写，菜单项小节永远不写这一行 |
| 本轮得分 | `x / 10`、`xxx / 710（无听力模拟折算分）`、未评分 `—`；保存失败且已放弃写 `评分未保存（已放弃）` |
| 题量与错题数 | `N 题 / M 处错误`；有未作答时补 `（另有 K 题未作答）` |
| 主观题得分 | **仅套题写这一行**：`写作 x/15 · 翻译 x/15`；`复习` / `练习` 整行不写，校验器会按 kind 判断行数 |

### 每轮「菜单小节信息」

带习题的菜单项小节在自己的标题下写一张三行表（不加小标题、不折叠），字段固定：

| 字段 | 允许的写法 |
|---|---|
| 生成时间 | `YYYY-MM-DD HH:MM`（24 小时制），这一节真正写进笔记的时刻（写入脚本盖），也是文件级 `复习历史` 链接与跳转锚点用的时间 |
| 本轮得分 | `x / 10`，该小节题组的 0 至 10 分；这些练习只写笔记，不写规范记录 |
| 题量与错题数 | `N 题 / M 处错误`；有未作答时补 `（另有 K 题未作答）` |

这三行由校验器核对：`N` 必须等于该小节内实际题目数，`M` 必须等于该小节内实际写出的 `错题讲解` 块数
（判错、部分正确都算，**未作答 / 未完成 / 漏答 不算**），`K` 必须等于该小节实际判为未作答的题数。
历史小节没有这两行时校验器不拦（当时没有计分口径），新写入必须带上。

`题量与错题数` 由校验器核对：`N` 必须等于该轮题组小节（`## 本轮习题` 或带菜单项标题的题组小节）内实际题目数，`M` 必须等于实际写出的 `错题讲解` 块数
（判错、部分正确都算，**未作答 / 未完成 / 漏答 不算**），`K` 必须等于实际判为未作答的题数。
`M` 与写入错题的条数允许不同：属于目标知识点的错误计入扣分但不单独入库，独立错误才按判型落库；可迁移的错误写进它所属的知识分类（`vocabulary` / `phrases` / `grammar` / `usage`，笔记就落在对应目录、写对应必写栏），只有判不出类型、或只剩一次性证据价值的错误才落 `errors`。

## 内容要求

- **版式必须渲染后分行**：选项、小题、多行答案一律用列表项（`- A. …`、`- (a) …`、`- (1) …`），
  禁止 `A. … B. … C. … D. …` 挤在同一段。一题含多个待答句 / 多句答案（造句写若干句、多空、多小题）时，
  答案逐条写成列表项、一条一行（`- ① I …`、`- ② Can you …?`、`- a. …`、`- (b) …`）；裸换行只是软换行，渲染后会并成同一段，不能靠换行符分行。
- **例句 / demo 一句一行，不内嵌在要点行**：`## 讲解` 各栏与菜单小节 `**讲解要点**` 的顶层要点行只写规则、词表或结论；
  支撑它的例句、示例短语、demo 一律下沉为缩进子项（`  - I waited twenty minutes.（我等了二十分钟）`），
  一句一个子项，不要把两句例句用空格、`、` 或 `；` 串在同一行。折叠块例句步骤（`可迁移表达` / `正确表达`）同此口径：
  只有一条例句时可跟在标签同行，两条及以上必须逐条缩进成子项；正误对照 `❌ … → ✅ …` 仍按「一行一个错点一个改法」写；
  表格单元格里的例句留在格内，不拆成子项。
- `我的答案` 只写该题答案本身：去掉用户提交时的题号前缀与列表标记（`1. B`、`1) B`、`（1）B` 都记 `B`）；
  多题合并提交时按题号拆分，每道题只保留属于自己的内容，其余拼写和标点原样保留。不得为空，未作答写「不会」等实际回复。
  一题多句时序号（`①②③` / `(1)(2)` / `a. b.` / `(a)(b)`）保留在各列表条目内，不要堆在标签行后；标签行无内容时留空一行再接列表。选择题的大写 `A/B/C/D` 答案仍是裸字母，不拆成列表。
- 每道题都必须写 `知识点讲解` 折叠块，可以超出当前复习知识点；答对的题也要写，不能因为正确就省略。
  唯一例外是套题按 Passage/Part 合并讲解：同一段阅读或同一个 Part 只由该段第一题写折叠块，其余题在该位置写一行
  `**知识点**：同第 <n> 题`（`n` 必须是本节内更早、且真的写了 `知识点讲解` 的题号），校验器会核对指向。
- 完全正确的题只写 `知识点讲解`；错题和带可复用错误的题在知识点讲解之后再写 `错题讲解`，只讲本轮实际出现并已讲解过的错误。
- 未作答题同样先写 `知识点讲解`，再写一个 `错题讲解` 块（第 2 步写 `为什么答不出`），给出参考表达与卡点机制；
  不允许只留一行「未作答」而没有讲解。
- 套题同样使用上面的固定骨架：每题一个 `### <n>. <题型>`（写作记 `短写作`、翻译记 `翻译`），不额外加 Part 小标题。
  **按 Passage/Part 合并 `知识点讲解`**：每段阅读只在段内第一题写完整四步折叠块，同段其余题写 `**知识点**：同第 <n> 题`
  指向它；写作与翻译各自独立写块。这样 57 题的套题不会膨胀成 57 份重复讲解。`主观题得分` 填
  `写作 x/15 · 翻译 x/15`，`本轮得分` 填 `xxx / 710（无听力模拟折算分）`。套题笔记因此会明显长于普通复习，
  这是规则要求的结果，不要为了控制篇幅删减知识点讲解。
- **所有内容都结构化记录，禁止整段文字**：分点的讲解、要点、规则、对比结论一律写成有序列表、无序列表或表格，
  一个子点一行；练习作答按习题区模板逐题展开，不要退化成只留「题号 / 题型 / 判定」的汇总表。
- **正误对照一行只讲一个错点与一个改法**：写成 `❌ … → ✅ …` 时，一行只容纳一个错误写法与一个修正写法；
  错因写在 ❌ 那一侧（跟在 ❌ 例句之后的括号里），**不要放在 ✅ 之后**，否则读者会把错因当成在解释那个正确写法；
  同一错点的多个正确写法各起一行，不要用 `／` 把替代说法与错因串在同一行。校验器按「同一行出现两个及以上 ✅」拦下这种叠写法（表格行除外）。
- **示范英文一律附中文翻译**：`## 讲解` 各栏的例句、`## <菜单项>` 里「讲解要点」子项的例句 / demo、折叠块里的
  `可迁移表达` 与 `正确表达`，英文句子后都要紧跟中文全角括号译文（`I joined a studio after graduation.`（毕业后我加入了一家工作室））；
  场景对话台词例外：每轮英文台词下方缩进一个中文子项，角色名译为中文（Tom → 汤姆），后接台词译文，不写成行内括号；
  题型名、题目原句、选项、用户答案和 `home-cooked` 这类语言点名称本身不翻译。
- **译文质量（对话台词与故事段落，canonical 口径）**：以“说话人这一轮在交际里干什么”为翻译单位，做功能对等，
  不做词对词映射。写入前按下面三步自查：
  1. **定功能**：这句是提议 / 同意 / 拒绝 / 抱怨 / 感叹 / 附和……对谁说、什么场合；
  2. **定中文说法**：同一个中文场景里真人会怎么开口——功能词按功能译，搭配按整体译，状语归到所修饰的动作；
  3. **回读校验**：脱离英文原句读中文，凡是只能对照英文才懂、语序贴英文、单字硬对的，就是对译痕迹，重译。
  常见退化位置（示例，不穷举）：功能词（感叹 / 应答 / 附和）、固定搭配、时间地点方式状语。
  语体要求：对话译文用口语短句，故事译文按句群连贯成段；角色名译中文，台词不写成书面腔。
- **历史踩坑样本（反例对照，规则边界不随新增词例扩大）**：

| 英文片段 | 退化译法 | 自然译法 |
|---|---|---|
| `Classic.` | 太典型了 | 果然又是这套 / 老一套 |
| `split a pot of tea` | 分一壶茶 | 合点一壶茶分着喝 |
| `forget about it for ten minutes` | 忘掉这些十分钟 | 先别想这些，歇十分钟 |
| `Yes.`（回应 `Shall we...?` 提议） | 要 | 好啊 / 行 / 可以 |

- 校验器只能检查「有没有译文」与标点，判断不了译文自然度；自然度靠上面三步人工自查。
- 这条只约束**新写入或本轮改写的区块**，不回溯改造历史笔记：旧笔记里的英文例句缺译文时照原样保留，
  不要为了套规则批量补译、重排或改动历史讲解。

## 视觉标识（emoji 与图标）

emoji 只做**分区标识**，帮长笔记扫读时快速定位；结构仍由固定标题与固定标签决定。
校验器与写入命令在比对小节标题、讲解栏目标签时，都会先剥掉**行首**的装饰性 emoji 与其后的空格，
所以「`## 🎭 场景对话`」与「`## 场景对话`」算同一个小节，写与不写图标都不会被判成两份。

### 可以加图标的位置（装饰位）

| 位置 | 写法 | 说明 |
|---|---|---|
| 讲解栏目标签 | `📌 **核心含义**：` | 图标放在 `**` **之前**；标签文字本身不许改（`核心含义` 仍是必写栏） |
| 讲解要点字段 | `💡 **讲解要点**：` | 同上，图标一律在 `**` 之前 |
| 菜单项小节标题（文件级与日期区块） | `## 🎭 看一套…的完整场景对话` | 直接沿用菜单选项自带的图标；` - 01` / ` - 02` 序号仍写在标题末尾、加在文字后面 |
| 讲解正文的要点行首、正误对照 | `- 🔍 …`、`❌ … → ✅ …` | 纯内容层，没有结构含义；正误对照仍受「一行只讲一个错点与一个改法」约束 |

### 不能加图标的位置（结构位）

| 位置 | 原因 |
|---|---|
| `## 基础信息`、`## 讲解`、`## 本轮习题`、`# <YYYY-MM-DD HH:MM> · <复习/练习/套题>` | 解析入口，逐字匹配，一律保持纯文字 |
| 追踪表字段名（`生成时间` / `本轮得分` / `题量与错题数` …）、`**题目**` / `**我的答案**` / `**判定**` 字段名 | 写入与校验都按字面取值，加图标会读不到 |
| 折叠块四步标签（`- **本题知识点**：` …）与 `<summary>知识点讲解</summary>` / `<summary>错题讲解</summary>` / `<summary>场景对话原文 · <标题></summary>` / `<summary>故事原文 · <标题></summary>` | 四步流程与折叠块类型按字面识别 |
| `**判定**：` 之后 | 只允许 `✅ / ⚠️ / ❌` 三选一加一句短说明，不能追加别的图标 |
| 标题里的 ` - 01` 序号、文件名、记录 ID | 派生数据按字面比对 |

### 固定映射（同一含义始终用同一个图标）

| 栏目 / 字段 | 图标 | 栏目 / 字段 | 图标 |
|---|---|---|---|
| 核心含义 | 📌 | 语法机制 | ⚙️ |
| 语气与语域 | 🧭 | 错误机制 | 🧨 |
| 结构拆解 | 🧩 | 与相近结构对照 | 🔀 |
| 常见误用 | 🚫 | 可迁移句型 / 可迁移表达 | 🧱 |
| 发音 | 🗣 | 历史文化背景 | 🕰 |
| 使用场景与语气 | 🎯 | 结构与搭配 | 🤝 |
| 近义辨析 | 🥊 | 讲解要点 | 💡 |
| 细节拆解 | 🔍 | 记忆钩子 | 🧠 |

- 图标只能写在 `**` **外面**：写成 `**📌 核心含义**：` 会被当成另一个栏目名，必写栏核对直接失败。
- 一个栏目只用一个固定图标，不叠加、不按心情换；正文要点不必逐行挂图标，一个栏目一处即可。
- 图标只是装饰：去掉后所有规则照旧成立，所以旧笔记不必批量补图标，新写入的按本表执行即可。
- 派生数据同样不受影响：习题小节的隐藏锚点短哈希按剥掉图标后的标题算，补不补图标都不会换锚点、不会重排索引。

## 菜单项写什么

用户在题组结束后通过数字菜单继续学习时，先判断这一项产出了什么，再决定写到哪里：

- **讲解型（不带习题）**：`follow-up-learning` 的语法/词汇扩展、`scenario-dialogue` 的场景对话、`focus-story` 的小故事、
  `error-clusters` 的专题讲解、对比相近表达等，写成 `## 讲解` 之后的文件级小节（`append-explain-section`），不进日期区块。
- **带习题的选择**：文件级小节只写 `**讲解要点**`（第一轮写一次），本轮实际作答的题目写进日期区块里同名的小节
  （`append-section`），格式与本轮习题完全一致：`### <n>. <题型>`、`**题目**`（必须完整抄写原题，含全部选项与小题）、
  `**我的答案**`（原样照抄）、`**判定**`、`知识点讲解` 折叠块（错题再加 `错题讲解`）。
- **重复选择**：除场景对话与小故事外，同一菜单项不再重复记录——`append-explain-section` 返回 `duplicate: true`
  就停手，不要改名绕过；后续只把这一轮的新习题追加到日期区块。
- `scenario-dialogue` / `focus-story` 每选中一次都要落一份完整原文：第一次写文件级小节，第二次起用
  `append-explain-part` 追加到同一小节；只有一份原文时 summary 写 `场景对话原文 · <标题>` / `故事原文 · <标题>`，出现第二份后
  改成 `场景对话原文 1 · <标题> / 2 · <标题>`、`故事原文 1 · <标题> / 2 · <标题>`，块前不写任何标签行。
- `scenario-dialogue` 小节每轮对话：块内逐轮写英文台词；对话贴近日常，目标表达在自然出现的台词上加粗，至少出现一次即可，其余台词不强行重复该表达；每句台词下方缩进一个中文子项，角色名译中文（Tom → 汤姆）并附台词译文；只写讲解要点、不保留对话原文，等于这一段没有交付。
- `focus-story` 小节每段故事：块内逐段写英文叙事（关键时刻对目标表达加粗）、每段后紧跟一行中文译文，收尾三列表同样写在这个块内（叙事与译文之后），不放到 `</details>` 外面。
  只写讲解要点、不保留故事原文，等于这一段没有交付。
- 只记要点，不抄整段讲解原文；标题直接写用户选中的选项原文（不加编号和 `菜单：` 前缀）。
- **会切换题组的选项不记在本轮区块里**：`continue-review`、`review-path`、`familiar-review`、`mastered-review`、
  `explain-current-exercise`、`mastered-exam-paper`、`paper-history`、`continue-paper-attempt`、`retry-random-paper`
  开启的是新一轮，按新一轮自己的日期区块记录。
- 纯导航与查询（`status` 统计、重新打开菜单、`history`）不写。
- 本轮没有选择任何讲解型菜单项时，不追加菜单小节，也不要在习题后留空小节。
