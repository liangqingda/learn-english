## 讲解

**错误机制**：
- 把 notice 当成「提醒、告知」的动词，套进 please notice that… 的句式。

**为什么错**：
- note 作动词是「留意、注意」，固定说法 please note that… 用于开头提醒对方注意某事。
- notice 作动词是「注意到、察觉到」，强调感官上的发现，不能用来引出提醒内容。

**正确表达**：
- `Please note that the office closes at five.`（请注意办公室五点关门）

**可迁移表达**：
- `Please note that all forms must be signed.`（请注意所有表格都要签名）
- `Please note that the schedule has changed.`（请注意日程已变更）
