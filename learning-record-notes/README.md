# learning-record-notes

每完成一轮有实际作答的英语复习、聚焦练习或完整套题，`practice-learning-records` 会在此目录写一个 Markdown 笔记，用于事后复盘。

- 命名规则：`<YYYY-MM-DD>-<HHMM>-<category>-<slug>.md`，时间取本轮结束时的本地时间。`category` 为记录分类，混合知识点用 `mixed`，套题用 `paper`。
- 文件前半部分是「追踪」表格：记录 ID、状态变化、本轮得分、题量与错题数、目标知识点、累计复习次数、下次复习时间、生成时间。
- 后半部分是「本轮习题」：逐题记录题干、用户原样答案与判定；错题在同一题下方用 `<details>` 折叠块给出四步讲解（考点 / 为什么错 / 英语表达逻辑 / 正确表达与可迁移）。

笔记是可读副本，不是规范数据源：评分、状态、复习调度都以 `learning-records/`、`mastered-learning-records/` 和 `exam-papers/` 为准，删除笔记不会影响任何评分或复习计划。
